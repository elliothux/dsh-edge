# @open-compute/dsh-edge 0.12.0

First publish under the `open-compute` npm organization.

## Changes

- Rename the public package from `dsh-edge` to `@open-compute/dsh-edge`.
- Export an embeddable Worker runtime surface (`auth`, `http`, `instance`, `session-store`, `workspace`).
- Add `@open-compute/dsh-edge/build` with `buildWorker` and `assembleWeb` so hosts can consume versioned packages instead of a source checkout.
- Stage patched vendor packages and the Edge client plugin into the published tarball.
- Keep the CLI installer entrypoint as `dsh-edge`.
