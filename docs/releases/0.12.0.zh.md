# @open-compute/dsh-edge 0.12.0

首次发布到 `open-compute` npm 组织。

## 变更

- 将公开包名从 `dsh-edge` 重命名为 `@open-compute/dsh-edge`。
- 导出可嵌入的 Worker 运行时表面（`auth`、`http`、`instance`、`session-store`、`workspace`）。
- 新增 `@open-compute/dsh-edge/build`（`buildWorker` / `assembleWeb`），让宿主通过版本化包消费，而不再依赖源码 checkout。
- 将已打补丁的 vendor 依赖与 Edge 客户端插件打入发布包。
- CLI 安装入口仍为 `dsh-edge`。
